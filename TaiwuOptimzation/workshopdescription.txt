[h1] 过月性能优化 [/h1]

优化原版仍存在的 NPC 月行动规划与存档 IO 热点。运行时缓存只减少重复查询，不跳过或延迟世界结算；并行压缩保持原版存档格式。

[h3][b]不写入自定义存档数据，不改变原版世界结算屏障；可在已有存档中自由加入/取消本 Mod。[/b][/h3]

[h2]主要优化[/h2]
[list]
[*] NPC 月行动规划热路径优化：目标范围索引、关系/物品候选预过滤、target matcher 阶段缓存
[*] 主/副目标规划使用冻结快照，并在 primary ApplyAll 后按 delta 局部更新
[*] planning graph 最终邻接缓存，减少完整规划中的重复条件匹配
[*] 密闻传播阶段 occurrence holder count 聚合缓存
[*] 启用并行存档压缩后，working.db 复制与并行 DEFLATE 共用所选块大小
[*] 可选输出 NPC 规划、密闻月结和 SaveWorld 诊断
[/list]

[h2]兼容性[/h2]
[list]
[*] 所有缓存均为运行时数据；最终筛选、随机选择和行动执行仍使用原版逻辑
[*] 无法安全命中缓存时回退原版路径
[*] 并行压缩可独立关闭；关闭后数据库复制恢复原版 4KB 缓冲块
[*] 生成的 local.sav 可由未安装本 Mod 的原版游戏读取
[/list]

[b]“远区 NPC 行动点削减”是默认关闭的可选非等价功能；关闭时完全采用原版行动点规则。[/b]

[b]使用 Harmony Patch，可能与修改密闻月结、NPC 行动规划、NPC 月行动点或相同存档写入方法的 Mod 冲突。[/b]

[h2]优化更新#260705[/h2]
根据当前代码路径复核，月中帧预算计算只服务于“远区 NPC 行动点削减”的保护快照，不参与密闻优化、NPC planning 热路径缓存和存档 IO 优化。

该帧预算任务本身已有低预算限制，并且不会在过月、保存或战斗中继续推进；从代码结构上看，它不应成为地图移动或战斗卡顿的主要来源。

考虑到不同机器、存档和 Mod 组合下仍可能出现体感差异，本次新增“月中帧预算构建保护快照”开关。关闭后，普通游玩帧中将完全停止推进该保护快照，方便用户自行排查或规避相关体感问题。

此开关只影响可选非等价项“远区 NPC 行动点削减”的保护快照构建；不会关闭密闻反查表、NPC 行动规划缓存、存档 IO 优化，也不会改变原版过月结算屏障。

[h2]优化更新#260628[/h2]
这一版继续整理 NPC 月行动规划优化，把主/副目标规划之间的缓存屏障收束为更清晰的两段式结构：

primary planning 读取冻结快照，热路径只读，尽量避免 worker 线程锁竞争。

primary ApplyAll 串行执行后记录 location / relation / inventory delta，不在 planning 热路径里抢锁更新大表。

primary ApplyAll 完成后，根据 delta 局部发布更新后的目标索引 / 关系预过滤 / 物品持有人预过滤 / matcher 依赖版本，供 secondary planning 使用；只有覆盖面过大或状态不可证明安全时才回退到更保守的路径。

这一版还补充了静态 planning graph 邻接缓存，用于减少完整新规划时的条件/效果节点扫描；对后续复用已有规划的月份，热点仍主要在 PrepareContext、FilterActionTargets 和 matcher 判断上。

诊断日志新增或细化了 delta publish、affected block / area、target lookup、target matcher、relation / item prefilter、planning graph cache 等信息，方便判断当前存档到底卡在扫描、匹配、执行、组织更新还是保存阶段。

本次更新的重点不是改变 NPC 行为，而是把高频查找路径整理成“规划阶段冻结、写回阶段记录、下一阶段局部更新”的结构。对于 NPC 行动规划占比较高的后期档，预计可以进一步降低主/副目标规划阶段的等待时间，并让之后的维护更稳。
